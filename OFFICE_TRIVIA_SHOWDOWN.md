# **Office Trivia Showdown**

**Background**:

Fridays at Better Developers need more chaos. We want a quick trivia game we can fire up during a break — fast rounds, a ticking clock, and bragging rights on the line.

**Task**:
Build a timed trivia game: fetch questions, let the player answer against the clock, and show a final score.

**Requirements**:

- Fetch trivia questions from a public API (e.g. Open Trivia DB), or generate them if you'd rather build your own set.
- Multiple-choice gameplay with a visible countdown timer per question.
- Score tracking and a results screen at the end of a round.
- Loading and error states (e.g. API down, no questions returned).
- Runs locally with one command.

**Stretch ideas**:

- Difficulty selector or category picker.
- Local leaderboard (top scores stored between sessions).
- Streak bonus for consecutive correct answers.
- Sound effects or animations for right/wrong answers.
- Deploy to a public URL.

*(Focus: state management, timers, API integration, game logic, fun UX)*
